# Changelog

## 0.1.0 - 2026-08-14

### Features

- Initial release (PRD 0022 FR-002, plan 0036 P0-11). Puck-native wrapper
  over `@anvilkit/ui` `Select`: `options` array (label/value), `placeholder`,
  `defaultValue`, `triggerSize` and `disabled`. Single `trigger` style
  target — base-ui's `Root` renders no DOM and the popup is portal'd.
