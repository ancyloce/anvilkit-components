# Changelog

## 0.1.0 - 2026-08-14

### Features

- Initial release (PRD 0022 FR-002, plan 0036 P0-12). Puck-native wrapper
  over `@anvilkit/ui` `Card` with two slot regions (`content`, `footer`) —
  the first slot-bearing component package. Fields: `title`, `description`,
  `size`. Five style targets: root/title/description/content/footer.
